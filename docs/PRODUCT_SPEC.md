# Open IO 综合规格与变更记录

## 当前范围

Open IO 在 GitHub 账号 `w2478328197-arch` 下提供待办同步、提词卡、户外跑步心率看板的源码目录和三个功能下载入口。发布方式为源码增量包，版本 `v0.1.0`；基础源码固定为 Turbo1123/Turbo-IO 的 `ca7bc09fbbf036eaf32e90797302d1c798d9e5a4`。

每个下载包包含相同的共用增量源码、校验清单、构建工具和文档，默认功能不同。用户可以选择一项或组合，不能把三个包理解为三个可直接安装且互不关联的 App。手机扩展沿用厂商 iOS App；Watch 与手机 Bundle ID、开发团队保持匹配。提词卡和跑步使用同一份 TWK1，固件保留两项眼镜菜单。

## 发布与构建规则

- 公开内容只包含选定的文本源码、文档、测试和构建脚本。厂商 App、原厂／派生固件 ZIP、签名、个人配置及健康记录不在公开包内。
- `prepare` 校验增量文件 SHA-256，只从固定提交创建新目录，不覆盖用户已有工作区。
- `build` 按功能配置启用本次新增手机入口与运行时；Watch 按配置显示提词卡或跑步入口。仅提词卡的 Watch 不声明 HealthKit 与运动后台能力。
- `sign-watch` 仅在用户明确提供团队与设备后请求 Xcode 本机签名。`package` 检查扩展身份、配置与固件配对；不会发起设备升级。
- 固件重建锁定工具链、原厂输入、AP 校验、其余 13 个负载及 ZIP 身份。TWK1 ZIP 固定时间元数据，重建后完整哈希须为 `c9f441bced48ff56782f23ccdcc42c0545bda5ac719f8c6fa8429d8c24a619a4`。
- 当前许可为 PolyForm Noncommercial 1.0.0，保留上游与第三方声明；源码可见不代表允许任意商用或取得厂商再分发权。

## 2026-09-28 · v0.1.0

- **模块**：发布目录、手机与 Watch 功能配置、固件重建、文档。
- **修改前**：三个功能混在本机开发版本中，没有独立的公开下载入口；构建参数和固件配对依赖本机操作。
- **修改后**：新增三个默认功能源码包和组合选择；校验清单与固定上游源码可重建工作区；新增本机构建、Watch 签名、精确 TWK1 打包入口；仅提词卡的 Watch 移除跑步能力声明。
- **原因与依据**：使用者要求按功能提供下载，随后指出厂商 App 再分发及开发者会员限制，因此明确交付源码和自行构建路径。
- **修复**：跑步单项配置仍启动共用 WatchConnectivity 接收器；手机打包时校验 Watch 的功能配置，拒绝混入另一项的手表产物；固件 ZIP 时间戳固定，使相同负载能重现已验收文件身份。未修改心率公式、区间来源、步频时间窗或缺失处理。
- **影响范围**：Open IO 增量源码与构建产物；原有私人开发目录和已安装设备不改动。功能选择只控制本项目新增入口与运行时，继承的 Turbo IO 基础界面仍存在。
- **验证结果与未决项**：见验证记录；公开源码不构成普通用户可直接安装的商店版。若未来改为独立原生 App 或 TestFlight 分发，需要另行实现宿主替代与权利核对。
