# 提词卡

选择 `cue` 配置，用手机整理演讲内容，在眼镜上逐张显示。手机支持建立、编辑及 Markdown 导入；手表可以读取卡组，在当前卡片后追加内容。手表新增需要手机可达，连接失败时会明确提示。

安装步骤见 [构建与安装](INSTALL.md)。手机与眼镜为必需设备，手表可选；眼镜使用配对的 TWK1 固件。

手机进入“提词卡”，建立或打开卡组，点“在眼镜上开始”。使用手机、手表或眼镜操作键翻页；眼镜触控右滑返回上一张，左滑进入下一张。手表支持的双指互点动作在抬腕、系统允许识别手势时触发下一张，最后一张不会继续越界。

在演示过程中追加的卡片保存到卡组，当前演示使用启动时的快照；结束再开始后载入更新内容，并从第一张开始。启动前应结束眼镜上占用显示通道的其他任务。

原组合版已经由项目使用者确认：手机编辑保存、手表追加有效、三端翻页同步、末页边界、重启回到第一张、启动不再闪现微信读书。这次源码发布新增的功能选择配置已完成编译和离线回归，尚未对每个用户签名配置逐一实机验证。
