# 心率看板 · 户外跑步

选择 `run` 配置，由 Apple Watch 开始室外跑步，手机把本次运动样本传到眼镜。眼镜显示心率和配套运动数据；结束时由手表保存到 Apple 健康，健身 App 显示系统同步结果。

安装步骤见 [构建与安装](INSTALL.md)。需要 iPhone、Apple Watch 和配对的 TWK1 眼镜固件。Watch 的签名必须允许 HealthKit，并取得用户对相应健康数据的授权。

1. 手机打开“运动看板”，保持与手表、眼镜连接。
2. 手表打开 Open IO →“运动看板”→“开始室外跑步”，按系统提示授权。
3. 心率出现后，在手机开启眼镜显示，或从眼镜首页进入“运动看板”。
4. 跑完在手表结束并保存，确认保存结果，再到 Apple 健身中查看。

心率区间使用系统提供且获准读取的范围；步频根据本次步数计算，热量使用活动热量。没有样本或样本过期时显示缺失状态，不填入估计心率。仅关闭眼镜显示不会结束手表运动。

手机实现了后台传输路径，但它仍是手表与眼镜之间的中转设备；连接中断、系统限制或权限不足会影响更新。本次已有明确实机反馈覆盖手机前台时心率和右侧数据持续更新，以及结束保存后健身 App 可见。新发布配置的长时间锁屏、断连恢复与不同系统版本仍需各自验证，不承诺脱离手机独立使用。
