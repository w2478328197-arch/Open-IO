# 待办同步

选择 `todo` 配置，把眼镜待办与 Apple 提醒事项连接起来。手机负责读取官方待办状态、保存对应关系、处理完成回执，并对重复事件去重。

安装步骤见 [构建与安装](INSTALL.md)。此配置无需安装本项目的 TWK1 眼镜固件，也不需要 Apple Watch。

首次使用在 iPhone 上授权提醒事项访问，连接眼镜，在待办页面检查列表和关联结果。先用一条可删除的测试待办确认创建与完成状态，再使用自己的正式内容。权限被拒、记录未关联或连接中断时，以页面提示为准，不把“请求已发出”当成“已经同步”。

这里只同步代码支持并能确认身份的记录，不会根据同名文本无条件合并所有提醒事项。多条同名内容需要核对关联；删除和完成是不同操作。具体行为由增量源码中的 `TodoRuntime.m`、`TodoMirror.m`、`TodoCompletionLedger.m` 与 `AppleCalendarSync.m` 实现。

本次发布对该配置做手机编译及待办协议、记录对应、冲突和去重的离线验证；未为新的独立签名配置再次完成全套设备验收。
